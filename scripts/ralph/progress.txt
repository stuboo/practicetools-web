## Codebase Patterns
- Zod is now installed for validation; project also uses Yup for Formik forms — use Zod for care-pathway schemas
- Types use `export type` pattern, page-specific types go in `src/pages/{page}/types.ts`
- Page modules: `index.tsx` + `types.ts` + `components/` + `hooks/` + `config/` subdirs
- API client pattern: frozen object with async methods using `apiClient` from `src/api/client.ts`
- React Query v4 (TanStack) — use `isLoading` not `isPending`
- Tailwind CSS for styling, Headless UI for behaviors, Heroicons/Lucide for icons
- Routes defined in `src/App.tsx`
- React Router 6.12 — use `unstable_useBlocker` (not `useBlocker`) for navigation blocking
- Reducer actions exported from `src/pages/care-pathway/index.tsx` for child components to dispatch
- `void varName` pattern to suppress TS unused-variable warnings for vars needed in future stories
- Lucide icons don't accept `title` prop — wrap in `<span title="...">` for native tooltips
- react-dnd v16 with HTML5Backend — DndProvider wraps the builder, each item is both drag+drop. Hover-based reorder with `item.index = index` mutation for smooth tracking
- ESLint worktree issue: use `--resolve-plugins-relative-to .` flag to avoid duplicate plugin error
- Pure utility functions go in `src/pages/care-pathway/utils/` for testability (e.g., formatNurseProtocol)
